CONVERTING TO DAYZ PAA:
1. Use ImageToPAA with these PNGs.
2. Convert all images, preserving alpha.
3. Place PAA files in your mod UI texture directory.
4. Assign idle/hover/selected/disabled images to DayZ widgets in the .layout and scripts.
5. Use image widgets with keep-aspect or stretch as appropriate. Avoid scaling rounded corners excessively.

All supplied PNG sizes are power-of-two. Buttons, cards, panels and backgrounds have no embedded text; use DayZ TextWidgets and live data.

IMPORTANT: Real 3D vehicle thumbnails, actual inventory item renders, saved attachments, tooltips and progress percentages are dynamic and CANNOT be supplied as generic static textures. They require the existing working game code.

The reference image in 09_reference is for comparison, not conversion.

The 2048x1024 background is a scalable UI skin, not a screenshot recreation with vehicles baked in.
